# Sableline Connector Hub

This repository holds connector package definitions submitted by partner
teams together with the submission tracker. Packages are grouped by
maintainer:

    submissions/<maintainer>/<connector>/

The reference layout and the written content rules live in
`reference/golden-connector/`. Every submitted package is tracked as an
issue in this repository, one issue per package; the verdict is recorded
on the issue's `Status:` line.
